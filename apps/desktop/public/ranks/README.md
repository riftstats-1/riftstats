# Rank emblems

Put Riot's official ranked emblems here, one PNG per tier, named in lowercase:

iron.png, bronze.png, silver.png, gold.png, platinum.png, emerald.png,
diamond.png, master.png, grandmaster.png, challenger.png

Download them from the Riot Developer Portal (developer.riotgames.com → Docs → League of Legends,
search for "Ranked Emblems"). Until a file exists the app shows a fallback badge in the tier color.
